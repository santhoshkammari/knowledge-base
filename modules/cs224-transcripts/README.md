# cs224-transcripts

Transcripts for Harvard **Advanced Algorithms (COMPSCI 224)**.

- Playlist: https://www.youtube.com/playlist?list=PL2SOU6wwxB0uP4rJgf5ayhHWgw7akUWSf
- All available lecture transcripts are in `cs224/transcripts/`.
- Lectures 1-13 use YouTube auto-captions. Lectures 15-26 use Phonon-2 streaming ASR on English-original audio.
- The playlist has no Lecture 14.
- Scripts: `pull.py` (captions), `dl.py` (English-original audio via yt-dlp), `towav.py` (16 kHz mono conversion), `stream_asr.py` (Phonon-2 pause-bounded streaming), and `remake_phonon2.sh` (rebuild ASR transcripts).
- See `cs224/STATUS.md` for provenance and caveats.
